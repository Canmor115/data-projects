# Auditoría de cartera y Cálculo de pérdida esperada (Expected Loss)

Motor de Credit Scoring y valoración de pérdida esperada sobre una cartera real de préstamos al consumo de Lending Club, combinando un modelo de probabilidad de impago (PD) con un modelo de severidad (LGD) para estimar cuánto dinero se espera perder por impagos. 

Cuando una entidad financiera quiere adquirir una cartera de créditos, ¿qué aspectos evalúa antes de tomar la decisión? No puede simplemente fiarse de los tipos de interés aunque parezcan bastante rentables a primera vista.

---

## 📋 Descripción del problema

Este proyecto simula la decisión de una entidad financiera que se plantea comprar una cartera de préstamos de Lending Club. 

A pesar de que los tipos de interés sean atractivos, el primer paso es estimar el riesgo real de impago de la cartera al completo, y con eso, la pérdida económica que va a suponer. Solo así se puede saber si el precio que piden por la cartera compensa o no.
